FreshConnect Local
## Overview

FreshConnect Local is a hyperlocal B2B marketplace designed to reduce food waste by connecting restaurants with surplus food to NGOs, caterers, and students in real time. The platform enables businesses to recover value from excess food while improving access to affordable, quality meals.



## Problem

Restaurants generate 5–25% food waste daily due to demand unpredictability, while NGOs and budget-conscious consumers face frequent shortages.

Key challenges:

* No structured redistribution channel
* Timing mismatch between surplus and demand
* Lack of food safety trust
* Unreliable supply


## Solution

FreshConnect Local enables:

* Real-time surplus listing by sellers
* Proximity-based discovery for buyers
* QR-based pickup system
* Auto-generated food safety logs


## User Research

* Conducted **25+ interviews** across restaurants, NGOs, and buyers
* Identified operational and trust-based challenges

## Key Insights:

* Restaurants waste **5–25% food daily**
* NGOs face **2–3 supply shortages/month**
* Safety and reliability are top concerns
* Timing gap is the biggest failure point


##  Key Features

* Role-based onboarding (Seller / NGO / Student)
* Quick listing creation (under 2 minutes)
* Proximity-based feed
* One-tap reservation with QR code
* Auto-generated safety documentation
* Budget filters for students
* Bulk filters for NGOs


##  User Flow

1. Seller posts surplus food
2. Buyers receive real-time alerts
3. Buyer reserves listing
4. QR code generated
5. Pickup completed
6. Safety log auto-generated



##  MVP Scope

Core flow:
**Post → Browse → Reserve → Pickup**
